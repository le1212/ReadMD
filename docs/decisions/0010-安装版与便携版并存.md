# 决策：日常使用改用安装版，便携版保留

- 日期：2026-11-16
- 状态：已采纳

## 背景

用户从资源管理器选择 `.md` 文件、用 ReadMD 打开时，便携版启动接近一分钟。原因不是应用代码慢，而是 electron-builder 的 `portable` 目标每次启动都会把约 105 MB 的应用解压到 `%TEMP%`，退出后再删除；文件越多、磁盘和杀毒软件越慢，启动越久。`portable.unpackDirName` 只改变解压目录，仍然每次解压。

## 对标与调研

| 产品 | 做法 | 启示 |
| --- | --- | --- |
| Visual Studio Code | 提供系统安装器，安装后直接启动；文件关联由安装器/运行时注册 | 日常使用应以安装版为主 |
| Typora | 安装器安装到本地目录，启动无需解压 | 单文件绿色版不适合作为日常默认程序 |
| Obsidian | 安装器安装；便携版单独提供 | 安装版与便携版可以并存 |
| electron-builder `portable.nsi` | 每次 `RMDir /r` 后 `File /r` 解压，`ExecWait` 结束后删除 | 便携版的启动开销是设计使然，无法靠应用代码优化 |
| electron-builder `fileAssociations` | Windows 只在 `nsis.perMachine = true` 时写入 | 不为了关联改成全机安装；继续用应用运行时写 HKCU |

## 决策

1. 新增 **NSIS 安装版**：`ReadMD-*-setup.exe`，`oneClick`、按当前用户安装（`perMachine: false`），不需要管理员权限；安装后从开始菜单/桌面启动，启动不再解压。
2. **便携版继续保留**：`ReadMD-*-portable.exe`，用于 U 盘、临时机器和无安装权限的场景。
3. 安装版首次启动仍由 `ensureFileAssociation()` 写入当前用户的“打开方式”候选，并自动把命令更新为安装路径；不修改 `UserChoice`。
4. 安装版不启用 NSIS 的 `fileAssociations`（它要求全机安装），避免为了文件关联引入管理员权限。
5. 文档中把安装版标为“推荐日常使用”，便携版标明“启动需解压，首次打开较慢”。

## 影响与风险

- 安装版会写入开始菜单和桌面快捷方式；卸载时保留 `%APPDATA%\ReadMD` 里的设置和 API Key，重装后继续使用。
- 仍未签名，SmartScreen 可能提示“未知发布者”，与便携版一致。
- 便携版启动慢的问题不会消失，但不再作为默认推荐；需要便携时接受这个代价。
- 启动时间实测（同一台机器，隔离配置）：安装版布局约 3.1 秒出现窗口；便携版受解压和杀毒扫描影响，约 20–60 秒。
